# Static prototype

`index.html` is the original single-file prototype of the Elestar interface. It
is kept for reference: it is where a lot of the visual system was worked out, and
the copy in it is worth reading before rewriting any of the product's wording.

It is **not** the application, and Next.js does not serve it. The product lives
in `app/` and `components/`. Open this file directly in a browser if you want to
look at it.

Nothing in the application imports from this folder, so it can be deleted
whenever it has stopped being useful.
